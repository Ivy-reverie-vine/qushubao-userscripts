# 数据中心 · 「复制启用表名」按钮方案

日期：2026-11-10
目标页：`https://dep.ai-indeed.com/mallQuan/dataCenter`
载体：`qushubao-userscripts.user.js`（新增到既有 `dataCenter` 页面模块，不新增文件、不引入依赖）
前置能力：同页已有「导出Excel」列（见 `2026-11-10_数据中心表字段导出Excel方案.md`）

## 一、需求（已与用户确认）

| 项 | 结论 |
| --- | --- |
| 按钮语义 | **复制出去**：点击后把启用表的名字拼成多行写入剪贴板，不改页面、不改站点数据 |
| 数据来源 | 已展开的嵌套表里「是否启用」= 启用的行 |
| 范围 | 页面默认全部连接器展开 → 默认行为取**全页所有已展开嵌套表**；`Alt + 点击` 只取按钮所在的那张表 |
| 输出格式 | 纯名单，一行一个，`\n` 分隔，无表头、无前缀、无引号 |
| 按钮位置 | 嵌套表表头 `表中文名称` / `表英文名称` 两个 `th` 内各一个 |

期望结果示例（连接器「万相台无界-账户现金收支明细」下 2 张启用表）：

```
万相台无界账户收支明细
万相台无界账户收支明细现金收支明细
```

## 二、结论

能做，纯 DOM 读取，**不需要任何接口**，与 `@grant none` 完全兼容。三个技术点都已有现成做法或标准 API：

| 块 | 做法 | 风险 |
| --- | --- | --- |
| ① 按钮注入 | 按表头文字反查 `th`，追加自己的 `<button data-qsb-paste>` | Ant Table 重渲染会抹掉 → 观察器补插 |
| ② 启用状态读取 | 单元格内 `.ant-switch-checked` / `input.checked` / 文字匹配，三级判定 | 站点改渲染形态 → 见 §4 兜底 |
| ③ 写剪贴板 | `navigator.clipboard.writeText` → `execCommand('copy')` → 可复制文本框 | 权限被拒时降级，不静默 |

## 三、按钮注入

嵌套表结构（单表结构，`thead` 与 `tbody` 同在一个 `<table>`）：

```
表中文名称 | 表英文名称 | [导出Excel] | 更新时间 | 清洗规则 | 映射规则 | 校验规则 | 操作 | 是否启用
```

- 列索引一律用已有的 `headerIndex(table, '表中文名称' | '表英文名称' | '是否启用')` 反查，**不写死数字**。
- 在命中 `th` 内追加（不动 React 管的文本节点，只 append 自己的子元素）：

```html
<th>表中文名称<button class="qsb-copyname-btn" data-qsb-copy="cn">复制</button></th>
```

- 按 `th button[data-qsb-copy]` 去重，已存在就跳过；`th` 被 React 重建时由同一个 `exportObserver`（300ms 防抖）补插。
- 样式：12px、行内、`margin-left:6px`、`vertical-align:middle`、`white-space:nowrap`，不撑高表头；`th` 本身不加 `padding` 改动，避免影响站点布局。

## 四、启用状态怎么读（已用真实 HTML 确认）

真实结构（用户提供的展开行 HTML，2026-11-10）：

```
表中文名称 | 表英文名称 | [导出Excel] | 更新时间 | 清洗规则 | 映射规则 | 校验规则 | 操作 | 是否启用
<td>万相台无界账户收支明细</td> ... <td><button role="switch" aria-checked="true" class="ant-switch ant-switch-checked"></button></td>
```

- 启用 = 最后一列 `button[role="switch"]`，**`aria-checked="true"` + `.ant-switch-checked`**；停用 = `aria-checked="false"` 且无 `ant-switch-checked`。
- 该连接器 4 张表，2 张启用 → 期望输出两行，与用户预期一致，已作为用例固化。
- 表名格是纯文本 `<td>`，无 tooltip 包裹，`textContent` 可直接用（有 `_月` 这类后缀，原样保留）。

脚本按三级判定兼容站点改版：

| 优先级 | 形态 | 判定 |
| --- | --- | --- |
| 1 | antd Switch | `aria-checked` 优先，退化看 `.ant-switch-checked` |
| 2 | checkbox | `input[type=checkbox]` 的 `.checked` |
| 3 | 纯文字 | 文本含 `未启用/停用/禁用/关闭` → 停用；含 `启用/开启/正常/是` → 启用 |

三级全落空（或整列找不到）时**不做静默猜测**：

- 该列全部表名照抄，`console.warn` 打出扫描表数，按钮反馈位数照常；
- 控制台日志末尾追加「含启用状态未识别的行」，说明口径可能不纯。

## 五、取值与输出

```
遍历 document.querySelectorAll('.ant-table-expanded-row table')
  → 对每张表取 目标列文本 + 是否启用 列
  → 只留启用行 → trim → 去空 → 去重（Set，保序）→ join('\n')
```

- 顺序 = DOM 顺序（外层连接器行序 → 表行序），不排序，便于和页面肉眼对照。
- 跨连接器汇总时按表名去重：纯名单里同名两次没有意义（参考文档里 `sycm_category_commodity_rank` 这类同名跨连接器表，中文名也可能撞）。
- `表中文名称` 单元格若有省略号/tooltip 结构，取 `textContent.trim()` 后再去掉尾部 `…`。
- 只读 DOM，不读接口，不缓存，**每次点击实时抓**（开关一改立刻生效）。

## 六、写剪贴板（三级降级）

1. `navigator.clipboard.writeText(text)` —— 点击手势内调用，HTTPS 同源，Chrome/Edge 正常；
2. 失败 → 临时 `textarea`（`position:fixed;top:-1000px`）+ `select()` + `document.execCommand('copy')`；
3. 再失败 → 弹一个只读文本框（`class="qsb-copy-fallback"`，`z-index` 高、可拖动不需要）展示名单并 `select()` 全选，提示「请按 Ctrl+C」。

按钮反馈：`复制 → 已复制 N 条`（1.5s 后恢复，复用 `setExportBtn` 同款写法）；`N=0` 时显示「无启用表」。

1. 展开「万相台无界-账户现金收支明细」→ `表中文名称`、`表英文名称` 两个表头各出现一个「复制」按钮，表头不变形、不换行。

3. 点英文列按钮 → 得对应英文表名两行。

5. 折叠再展开、翻页、刷新、切页 → 按钮不重复、不消失。
6. 只展开 1 个连接器时 `Alt+点击` 与普通点击结果一致；展开多个连接器时普通点击汇总全部。
7. 拒绝剪贴板权限（Chrome 站点设置里禁用）→ 降级到文本框，能手动复制，不静默失败。
8. 某页一个启用表都没有 → 反馈「无启用表」，不写空字符串进剪贴板。
9. `node --test tests/core.test.mjs` 全绿（本次不动内核，不强制补用例）。

## 九、风险与退路

| 风险 | 影响 | 处置 |
| --- | --- | --- |
| 是否有「是否启用」列（列序/名称与文档不一致） | 取不到状态 | 反查不到列时按「全部表」降级并明示，不静默 |
| 启用状态是图标/自定义组件 | 识别不出 | 三级判定 + 打 `outerHTML`，现场按真实结构补一条规则 |
| 站点改 `ant-table-expanded-row` 类名 | 抓不到嵌套表 | 兜底再找 `.ant-table-expanded-row` 的下一级 `table`；类名变了要改一行 |
| 全页展开但只算当前分页 | 名单不完整 | 页面提示「仅当前页」，需要全量就翻页后再点（不做自动翻页，避免打站点接口） |
| 剪贴板 API 被策略禁用 | 点击无反应 | 三级降级，最差给可手动复制的文本框 |

## 十一、遗留

1. 只覆盖**当前页**已展开的连接器（页面是分页的），跨页需翻页后再点。
2. 若站点把「是否启用」重做成图标或无 `aria-checked` 的自定义组件，需要按新结构补一条判定（当前三级判定已覆盖 switch/checkbox/文字三种）。
3. 输出按表名去重；如需保留跨连接器同名表的重复，去掉 `collectEnabledNames()` 里的 `seen` 判断即可。
